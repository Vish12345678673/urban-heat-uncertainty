# Archived Experiments

This directory contains exploratory experiments used during development of the
YCEO-UHI distribution-shift and uncertainty framework.

These experiments are retained for reproducibility and research provenance but
are not part of the primary reproduction pipeline.

The primary results are generated from the maintained code under:

- code/modeling/
- code/uncertainty/
- code/analysis/

Final paper outputs are stored in:

- results/final_paper/
